NOTE ON REPRODUCIBILITY & HARDWARE OPEN SOURCE

All CAD models are modeled natively in SolidWorks with parametric master sketches. Electronics schematics and multi-layer PCB gerbers are generated using KiCAD. Microcontroller firmware uses ANSI C/C++ running bare-metal or on FreeRTOS with zero dynamic memory allocation in runtime control loops. Detailed design docs and build logs accompany each project.
